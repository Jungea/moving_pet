# Release Notes — v0.6.0

릴리즈 날짜: 2026-10-15

## Added

- 선택한 모니터의 작업 영역 레이아웃 IPC
- 트레이의 모니터 선택 메뉴
- 상·하 방향을 포함한 네 방향 걷기
- 선택된 모니터 작업 영역 보정 단위 테스트

## Changed

- 트레이에서 선택한 모니터의 작업 영역만 투명 펫 창으로 덮습니다.
- 펫은 선택된 모니터 밖으로 드래그하거나 이동할 수 없습니다.
- 펫 placeholder의 표시 크기를 112 × 116px에서 28 × 29px로 축소했습니다.
- 상태 패널과 반응 텍스트의 위치를 축소된 펫에 맞췄습니다.
- 트레이의 펫 아이콘과 종료 메뉴를 v0.6 동작 기준으로 확인했습니다.
- Windows 알림 영역 호환성을 위해 32px PNG 트레이 아이콘을 등록합니다.
- 프로젝트 버전을 `0.6.0`으로 올렸습니다.
- 자동 테스트를 20개로 확장했습니다.

## Deferred

- 실제 캐릭터 디자인과 스프라이트 애니메이션
- 대각선 이동과 모니터 배치 설정 UI
- 인벤토리, 아이템, 재화
