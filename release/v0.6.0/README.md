# Moving Pet v0.6.0

기존 기능의 사용성을 다듬는 안정화 릴리즈입니다.

## v0.6.0 기능

- 펫이 선택한 모니터의 작업 영역 안에서 상·하·좌·우로 이동합니다.
- 트레이 메뉴의 **펫 표시 모니터**에서 모니터 1·2 등을 선택할 수 있습니다.
- 모니터를 바꾸면 펫 창과 드래그 범위가 해당 작업 영역으로 즉시 제한됩니다.
- CSS placeholder 펫을 기존 가로·세로의 1/4인 28 × 29px로 축소했습니다.
- `npm start` 실행 시 시스템 트레이의 펫 아이콘과 **종료** 메뉴를 사용합니다.

## 실행 및 검증

```powershell
npm start
npm run check
```

처음 설치하는 경우 `npm ci`를 먼저 실행합니다. 자동 검증은 총 20개 테스트를 실행합니다.

## 수동 확인

1. 펫이 상·하·좌·우로 이동하는지 확인합니다.
2. 펫을 드래그해 선택한 모니터의 작업 영역 안에서만 움직일 수 있는지 확인합니다.
3. 트레이의 **펫 표시 모니터**에서 모니터를 바꾸면 펫이 해당 화면에 표시되는지 확인합니다.
4. 작업 표시줄 알림 영역의 펫 아이콘을 우클릭해 **종료**가 동작하는지 확인합니다.

## 제한사항

- 대각선 이동과 모니터 배치 편집 UI는 제공하지 않습니다.
- 실제 캐릭터 이미지와 스프라이트 애니메이션은 v1.0 범위입니다.
