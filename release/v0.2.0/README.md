# Moving Pet v0.2.0

클릭·드래그 상호작용과 `sleep` 행동을 추가한 Desktop Pet 2차 프로토타입 릴리즈입니다.

이 릴리즈는 개발 및 기능 검증을 위한 소스 기반 릴리즈입니다. Windows 설치 파일이나 자동 업데이트는 포함하지 않습니다.

## v0.2.0 기능

- 좌클릭 시 짧은 `pet!` 반응과 애니메이션
- 드래그로 펫을 화면 안 원하는 위치에 배치
- 드래그를 놓은 위치에서 행동 재개
- `idle → walk → sleep` 행동 순환
- 수면 중 `zzz` 표시와 수면 애니메이션
- 기존 transparent window, click-through, 좌우 이동, 트레이 종료 유지

## 실행

요구 환경:

- Windows 10/11
- Node.js 22.12 이상
- npm

프로젝트 루트에서 실행합니다.

```powershell
npm ci
npm start
```

## 검증

```powershell
npm run check
```

자동 검증은 행동 전환, 이동 경계, sleep 중 정지를 포함한 3개 단위 테스트를 실행합니다.

## 수동 확인

1. 펫이 없는 투명 영역을 클릭해 뒤의 Windows 앱이 입력을 받는지 확인합니다.
2. 펫을 한 번 클릭해 `pet!` 반응이 표시되는지 확인합니다.
3. 펫을 드래그해 다른 위치에 놓고, 그 위치에서 다시 행동하는지 확인합니다.
4. `idle`, `walk`, `sleep` 및 `zzz` 표시를 확인합니다.
5. 알림 영역의 `Moving Pet` 메뉴에서 **종료**를 선택해 앱이 종료되는지 확인합니다.

## 제한사항

- 드래그 위치와 펫 상태는 아직 저장되지 않습니다.
- 다중 모니터는 지원하지 않습니다.
- 실제 스프라이트 대신 CSS placeholder를 사용합니다.
- 클릭은 반응만 제공하며 게임 상태를 바꾸지 않습니다.
- 육성, 아이템, 인벤토리, 친밀도, 배고픔은 구현하지 않았습니다.
