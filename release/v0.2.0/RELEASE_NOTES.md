# Release Notes — v0.2.0

릴리즈 날짜: 2026-10-15

## Added

- 클릭 반응: 좌클릭 시 펫이 짧게 반응하고 `pet!` 상태를 표시합니다.
- 드래그 배치: 펫을 잡아 현재 화면 작업 영역 안으로 이동할 수 있습니다.
- `sleep` 행동: 기존 `idle`, `walk`에 이어 수면 상태와 시각 효과를 추가했습니다.
- 위치 상태: 펫 상태가 `x`, `y` 좌표를 관리합니다.
- 감정 상태: 최소 `calm` / `happy` 상태를 추가해 상호작용 표현을 렌더러와 분리했습니다.
- 행동 테스트: sleep 전환과 수면 중 정지를 검증하는 단위 테스트를 추가했습니다.

## Changed

- 초기 펫 위치를 화면 하단으로 계산해 배치합니다.
- 드래그 중에는 입력이 끊기지 않도록 펫 영역의 상호작용 상태를 유지합니다.
- 클릭 또는 드래그가 시작되면 행동 타이머를 초기화해 예기치 않은 상태 전환을 피합니다.

## Architecture

- `PetState`는 행동, 방향, 기분, `x/y` 위치를 보유합니다.
- `BasicBehaviorSystem`은 시간 기반 행동 전환과 walk 이동만 담당합니다.
- `InteractionSystem`은 클릭 판정, 드래그 좌표 계산, click-through 상태를 담당합니다.
- `PetRenderer`는 상태를 DOM 데이터 속성과 transform에 반영합니다.

## Deferred

- 드래그 위치와 상태의 로컬 저장
- 행동 선택의 랜덤화 및 이벤트 시스템
- 먹이주기, 놀이, 친밀도, 에너지
- 실제 스프라이트와 프레임 애니메이션
- 다중 모니터, 설치 파일, 자동 업데이트
