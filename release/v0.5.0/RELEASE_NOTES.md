# Release Notes — v0.5.0

릴리즈 날짜: 2026-10-15

## Added

- `PetGrowthSystem`: 경험치 누적, 다중 레벨업, 최대 레벨 처리
- 레벨 및 현재 경험치 상태
- 레벨과 경험치 진행 바 UI
- 돌봄 행동별 경험치 보상
- `level up!` 반응 메시지
- 성장 시스템 단위 테스트
- 저장 포맷 v3과 v1/v2 마이그레이션

## Changed

- 상태 말풍선 상단에 레벨과 경험치 진행 상황을 표시합니다.
- 쓰다듬기, 먹이주기, 놀아주기가 돌봄 수치와 경험치를 함께 변경합니다.
- 프로젝트 버전을 `0.5.0`으로 올렸습니다.
- 자동 테스트를 16개로 확장했습니다.

## Deferred

- 레벨별 캐릭터 외형 및 성장 단계
- 레벨업 보상과 능력치 효과
- 아이템, 인벤토리, 재화
- 실제 스프라이트와 사운드
