# Moving Pet v0.5.0

경험치와 레벨을 추가한 Desktop Pet 5차 프로토타입 릴리즈입니다.

## v0.5.0 기능

- 상태 말풍선에 현재 레벨과 경험치 진행 표시
- 쓰다듬기, 먹이주기, 놀아주기로 경험치 획득
- 필요 경험치를 넘으면 남은 경험치를 유지하며 레벨업
- 한 번에 여러 레벨을 올릴 수 있는 성장 계산
- 레벨업 시 `level up!` 반응
- 최대 레벨 100
- 레벨과 경험치를 포함한 저장 포맷 v3
- 기존 v1/v2 저장 파일의 자동 마이그레이션

## 성장 규칙

| 행동 | 획득 경험치 |
| --- | ---: |
| 펫 클릭 | 1 |
| 먹이주기 | 3 |
| 놀아주기 성공 | 5 |
| 에너지 부족으로 놀이 거절 | 0 |

다음 레벨에 필요한 경험치는 `현재 레벨 × 20`입니다. 예를 들어 레벨 1은 20, 레벨 2는 40이 필요합니다.

## 실행 및 검증

```powershell
npm start
npm run check
```

처음 설치하는 경우 `npm ci`를 먼저 실행합니다. 자동 검증은 총 16개 테스트를 실행합니다.

## 수동 확인

1. 펫을 클릭해 레벨과 경험치 바를 확인합니다.
2. 쓰다듬기, 먹이주기, 놀아주기로 경험치가 증가하는지 확인합니다.
3. 경험치 기준을 넘으면 `level up!`이 표시되는지 확인합니다.
4. 앱을 재실행해 레벨과 남은 경험치가 복원되는지 확인합니다.

## 제한사항

- 레벨에 따른 외형 변화, 능력치 보너스, 보상은 아직 없습니다.
- 경험치는 현재 돌봄 행동으로만 획득합니다.
- 인벤토리, 아이템, 재화는 아직 제공하지 않습니다.
