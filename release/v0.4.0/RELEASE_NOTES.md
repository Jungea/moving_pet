# Release Notes — v0.4.0

릴리즈 날짜: 2026-10-15

## Added

- `PetCareSystem`과 테스트 가능한 먹이·놀이·쓰다듬기 규칙
- 친밀도 상태와 상태 말풍선 표시
- 먹이주기 및 놀아주기 버튼
- `pet!`, `yum!`, `fun!`, `tired...` 반응 메시지
- 에너지 부족 시 놀이 거절
- 친밀도를 저장하는 저장 포맷 v2
- v1 저장 데이터의 v2 자동 마이그레이션

## Changed

- 상태 패널을 펫과 함께 상호작용 가능한 click-through 예외 영역으로 처리합니다.
- 상태 패널과 펫 사이의 간격을 없애 포인터 이동 중 입력이 끊기지 않게 했습니다.
- 프로젝트 버전을 `0.4.0`으로 올렸습니다.
- 자동 테스트를 12개로 확장했습니다.

## Deferred

- 먹이 아이템 및 재화 소비
- 놀이 종류와 미니게임
- 친밀도 레벨 및 성장 보상
- 인벤토리와 꾸미기
- 실제 캐릭터 스프라이트
