# Moving Pet v0.4.0

먹이주기, 놀아주기, 친밀도를 추가한 Desktop Pet 4차 프로토타입 릴리즈입니다.

## v0.4.0 기능

- 상태 말풍선에 배고픔, 에너지, 친밀도 표시
- `먹이주기` 버튼과 `yum!` 반응
- `놀아주기` 버튼과 `fun!` 반응
- 에너지가 부족하면 놀이를 거절하고 `tired...` 표시
- 펫 쓰다듬기, 먹이, 놀이에 따른 친밀도 증가
- 친밀도를 포함한 저장 포맷 v2
- 기존 v0.3 저장 파일을 기본 친밀도 10으로 자동 마이그레이션

## 돌봄 규칙

| 행동 | 결과 |
| --- | --- |
| 펫 클릭 | 친밀도 +1 |
| 먹이주기 | 배고픔 -25, 친밀도 +2 |
| 놀아주기 | 에너지 -10, 배고픔 +4, 친밀도 +6 |
| 에너지 10 미만에서 놀이 | 수치 변화 없이 `tired...` 표시 |

모든 상태 값은 0에서 100 사이로 제한됩니다.

## 실행

```powershell
npm ci
npm start
```

기존에 의존성을 설치했다면 `npm start`만 실행하면 됩니다.

## 검증

```powershell
npm run check
```

행동, 필요 상태, 돌봄 규칙, 저장 마이그레이션을 포함한 테스트 12개를 실행합니다.

## 수동 확인

1. 펫을 클릭해 상태 말풍선을 엽니다.
2. `먹이주기`를 눌러 배고픔 감소와 `yum!` 반응을 확인합니다.
3. `놀아주기`를 눌러 에너지·배고픔·친밀도 변화와 `fun!` 반응을 확인합니다.
4. 앱을 종료하고 다시 실행해 친밀도까지 복원되는지 확인합니다.
5. 말풍선 밖의 투명 영역이 계속 click-through인지 확인합니다.

## 제한사항

- 먹이와 놀이는 횟수·아이템 제한이 없는 프로토타입 동작입니다.
- 앱이 꺼진 동안의 시간은 상태 변화에 반영하지 않습니다.
- 성장, 레벨, 인벤토리, 실제 스프라이트는 아직 제공하지 않습니다.
