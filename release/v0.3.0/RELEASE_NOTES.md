# Release Notes — v0.3.0

릴리즈 날짜: 2026-10-15

## Added

- `PetNeedsSystem`: 시간 기반 배고픔 증가, 에너지 감소 및 수면 회복
- `PetSaveSystem`: 버전이 지정된 JSON 상태 저장과 로드
- 저장 데이터의 타입, 숫자 범위, 위치 값 검증
- preload를 통한 제한된 `loadState` / `saveState` IPC API
- 배고픔과 에너지를 보여주는 클릭 상태 말풍선
- 여러 테스트 파일을 자동으로 실행하는 테스트 러너
- 상태 변화와 저장 시스템 단위 테스트

## Changed

- `sleep`은 고정 행동 순서가 아니라 에너지 상태로 결정됩니다.
- 위치, 방향, 행동, 배고픔, 에너지가 5초 주기와 드래그 종료 시 저장됩니다.
- 앱 시작 시 저장 상태를 화면 범위에 맞춰 복원합니다.
- 드래그 판정에 4px 임계값을 적용해 작은 포인터 움직임이 클릭을 방해하지 않습니다.
- 프로젝트 버전을 `0.3.0`으로 올렸습니다.

## Security

- 파일 입출력은 Electron main 프로세스에서만 수행합니다.
- IPC 요청은 현재 펫 창의 webContents에서 온 요청만 처리합니다.
- 저장 전에 모든 필드를 검증하고 예상하지 않은 데이터는 거부합니다.

## Deferred

- 먹이주기, 놀아주기, 친밀도
- 오프라인 시간 경과 계산
- 성장, 레벨, 인벤토리, 꾸미기
- 다중 모니터 및 설치 파일
