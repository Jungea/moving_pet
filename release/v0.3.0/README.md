# Moving Pet v0.3.0

로컬 저장과 최소 육성 상태를 추가한 Desktop Pet 3차 프로토타입 릴리즈입니다.

## v0.3.0 기능

- 배고픔과 에너지 상태가 시간에 따라 변화
- 깨어 있을 때 에너지가 감소하고 수면 중 회복
- 에너지가 20 이하이면 자동으로 잠들고 75 이상이면 기상
- 펫 클릭 시 4초 동안 상태 말풍선 표시
- 펫 위치, 방향, 행동, 배고픔, 에너지를 5초마다 로컬 저장
- 드래그 종료 시 즉시 저장
- 앱 재시작 시 저장 상태 복원
- 손상되거나 범위를 벗어난 저장 데이터는 무시하고 기본 상태 사용

## 실행

요구 환경:

- Windows 10/11
- Node.js 22.12 이상
- npm

```powershell
npm ci
npm start
```

기존에 의존성을 설치했다면 `npm start`만 실행하면 됩니다.

## 저장 위치

상태는 Electron의 사용자 데이터 디렉터리 아래 `save/pet-state.json`에 저장됩니다. Renderer는 파일에 직접 접근하지 않고 preload IPC를 통해 main 프로세스의 Save System을 사용합니다.

## 검증

```powershell
npm run check
```

행동, 배고픔·에너지, 저장 검증과 JSON 복원을 포함한 테스트 7개를 실행합니다.

## 수동 확인

1. 펫 클릭 시 배고픔과 에너지 말풍선이 표시되는지 확인합니다.
2. 펫을 다른 위치로 드래그하고 5초 이상 기다린 뒤 앱을 종료합니다.
3. 앱을 다시 실행해 위치와 상태가 복원되는지 확인합니다.
4. 투명 영역 click-through와 트레이 종료가 계속 동작하는지 확인합니다.

## 제한사항

- 앱이 꺼진 동안의 시간은 상태 변화에 반영하지 않습니다.
- 먹이주기와 놀아주기는 아직 제공하지 않습니다.
- 다중 모니터, 실제 스프라이트, 설치 파일은 지원하지 않습니다.
